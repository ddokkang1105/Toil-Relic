Grounding

Codebase Context

  • 콘솔과 Unity 모두 사냥 → 전투 → 보상/경험치 → 제작 → 반복이라는 핵심 루프를 이미 공유한다.
  • 저장 피드백, 장비 비교, HUD 중첩, 16:9 전투 패널, PlayMode QA에 이어 Purposeful Hunt와 Ironclad Save Envelope까지 완료되었다.
  • 기존 1순위였던 목적성 공백은 안내형 Hunt Contract, 사냥감별 보상, First Relic Project로 닫혔다.
  • 기존 2순위였던 저장 내구성 공백도 원자적 live 교체, last-known-good 보존·복구, 결정론적 장애 검증으로 닫혔다.
  • 이제 가장 큰 플레이어 체감 공백은 전투 표현력이다. Unity는 Attack/Defend/Flee/Potion을 제공하지만 적 의도를 미리 보여주지 않고, Defend는 평면적인 피해 감소다. 콘솔 전투는 여전히 자율 진행된다.
  • 게임플레이 변경은 콘솔과 Unity에 함께 반영해야 한다. Tactical Hunt Grammar는 콘솔도 턴별 플레이어 선택으로 전환해 이 비대칭을 직접 다루되, 새 버튼보다 공유 가능한 의도·대응 규칙에서 시작해야 한다.

순위 원칙: 원래 1·2순위가 모두 완료되어 목적성과 진행 보호 기반이 갖춰졌다. 남은 후보 중 즉각적인 플레이어 가치, 기존 시스템 활용, Quarry Mastery의 선행 조건을 함께 만족하는 Tactical Hunt Grammar가 가장 강한 다음 작업이다.

Updated 2026-08-11 · second continuation

Continuation Decision

다음 작업: Tactical Hunt Grammar. 공통 턴 문법은 각 플레이어 선택 전에 다음 적 의도를 공개·고정하고, Attack/Defend 한 번을 받은 뒤 예고한 적 행동과 결과를 해결하고, 전투가 계속되면 다음 의도를 공개하는 순서다. 콘솔은 이 턴별 선택을 직접 받고 Unity는 기존 전투 버튼을 사용한다.

  • 완료 근거: Purposeful Hunt와 Ironclad Save Envelope Personal Flow 태스크는 모두 QA와 close를 통과했다. Ironclad의 최종 검증은 콘솔 152개와 Unity Play Mode 176개의 통과를 기록한다.
  • 현재 결손: Unity의 전투 동사는 존재하지만 적의 다음 행동을 읽고 대응하는 규칙이 없고, 콘솔은 같은 동사를 플레이어 선택으로 제공하지 않는다.
  • 전술 증명: 첫 slice는 서로 다른 최선 대응을 요구하는 의도 최소 2개를 기존 적 패턴 1~2개로 증명한다. Attack만 또는 Defend만 반복하면 적어도 한 의도에서 불리한 결과가 보여야 하며, 나머지 적은 같은 문법의 기본 공격 의도를 사용한다.
  • 표현 계약: 모든 의도는 양쪽 런타임이 공유하는 짧은 텍스트 label을 갖는다. Unity는 색상에만 의존하지 않는 시각 상태를 함께 제공하고 콘솔은 같은 label과 의미를 텍스트로 보여준다.
  • 왜 지금인가: 원래 상위 두 기반 작업이 끝났고, 이 작업은 새 버튼을 늘리지 않으면서 전투 체감과 적 정체성을 함께 높인다. 이후 Quarry Mastery가 기록할 실제 학습 대상도 만든다.
  • 범위 상한: 완전한 콤보 시스템, 추가 전투 버튼, 대규모 적 로스터, Quarry Mastery/도감, 새 세션 구조는 포함하지 않는다.

1. Purposeful Hunt Vertical Slice

Confidence 88%Complexity High
Description
한 번의 안내형 Hunt Contract에서 소수의 사냥감을 고르게 하고, 2~3개의 사냥감별 드롭 프로필을 활성화하며, 재료가 하나의 활성 유물 프로젝트로 이어지게 한다. 첫 증분은 의도적으로 작게 유지해 기존 전투·보상·장비 비교·제작·저장·UI가 하나의 플레이어 목표를 이루게 한다.
Basis
direct: Unity에는 아직 쓰이지 않는 EnemyData.equipmentDropProfileId가 있고, 두 런타임 모두 승리 시 같은 고정 무기를 보상하며, 콘솔 제작은 한 레시피뿐이다. external: Against the Storm의 목표와 수정자 구조는 제한된 콘텐츠도 의도 있는 선택으로 묶을 수 있다는 선례다. reasoned: 개별 루프 단계의 품질을 이미 높였으므로 이제 가장 큰 레버리지는 단계들에 명시적인 이유와 보상을 주는 데 있다.
Rationale
“왜 다시 사냥해야 하는가?”를 해결하면서 이미 만든 시스템을 모두 실전 사용한다. 잘 다듬어진 프로토타입을 고유한 정체성이 있는 게임으로 옮기는 가장 강한 연결점이다.
Downsides
범용 계약 프레임워크로 확장하면 즉시 과대해진다. 첫 태스크는 안내형 계약 1개, 프로필 2~3개, 유물 프로젝트 1개, 양쪽 런타임의 결정론적 검증으로 상한을 고정해야 한다.

2. Ironclad Save Envelope

Confidence 96%Complexity Medium
Description
양쪽 런타임에 동일한 내구성 계약을 정의한다. 버전이 있는 저장 envelope, 임시 파일 쓰기, 원자적 교체, last-known-good 백업, 복구 메시지, 실패 주입 검증을 한 묶음으로 제공한다.
Basis
direct: 저장 UX 태스크가 원자적 쓰기와 last-known-good 복구를 높은 우선순위 후속 작업으로 이미 기록했다. 콘솔의 교체 로직에는 완전한 복구 경로가 없고 Unity는 현재 live 파일에 직접 쓴다. reasoned: 누적 진행은 충돌과 부분 쓰기에서도 살아남을 때만 가치가 보존된다.
Rationale
가장 안전한 고가치 작업이자 더 많은 진행 상태를 추가하기 전의 좋은 전제다. 독립 검증은 위험 감소와 납품 확실성을 기준으로 이 작업을 1위로 평가했다.
Downsides
플레이어는 문제가 생길 때 주로 체감한다. 현재 루프를 보호하지만 루프 자체를 더 흥미롭게 만들지는 않는다.

3. Tactical Hunt Grammar

Confidence 67%Complexity Medium–High
Description
적 의도를 미리 보여주고 Attack/Defend의 타이밍에 의미를 부여한다. 완전한 콤보 시스템보다 읽을 수 있는 적 패턴 한두 개에서 시작한다.
Basis
direct: 두 런타임은 Attack과 Defend를 이미 갖지만 콘솔 전투는 자율적으로 진행된다. reasoned: intent는 버튼 수를 늘리지 않고도 전술적 선택을 만들 수 있다.
Rationale
기존 전투 동사를 더 표현력 있게 만들고 적의 개성을 강화한다.
Downsides
정직한 기능 정렬을 위해 콘솔 상호작용도 다시 설계해야 하므로 겉보기보다 큰 교차 런타임 변경이다.

4. Quarry Mastery Loop

Confidence 61%Complexity High
Description
반복 조우가 공격 범위, 예상 드롭, 대응법을 드러내게 하고, 이후 숙련은 일상적인 사냥을 더 빠르게 처리할 수 있게 한다.
Basis
direct: 저장소는 작은 적 로스터와 반복 사냥 루프를 갖는다. reasoned: 지식 진행은 숫자 성장에만 의존하지 않고 반복을 플레이어 학습으로 바꿀 수 있다.
Rationale
반복 조우에 장기적인 의미를 주고 사냥감 정체성을 강화한다.
Downsides
적별 보상과 전술이 먼저 존재할 때 훨씬 강하다. 지금 만들면 얕은 차이를 기록하는 도감이 될 수 있다.

5. One Content Source, Two Runtime Builds

Confidence 58%Complexity High
Description
하나의 버전 관리형 중립 콘텐츠 카탈로그에서 콘솔 정의와 Unity 데이터 에셋을 생성하거나 검증한다.
Basis
direct: 저장소 정책은 두 구현의 게임플레이 기능 정렬을 요구한다. reasoned: 의미가 안정된 뒤의 공용 카탈로그는 드리프트를 줄이고 미래 콘텐츠 작업을 누적적으로 싸게 만든다.
Rationale
장기적으로 콘텐츠 추가 비용을 낮추고 parity를 증명하기 쉽게 한다.
Downsides
계약·드롭·제작의 의미가 아직 진화 중이라 지금 중앙화하면 잘못된 추상화를 굳힐 수 있다.

6. Relic Vow Commission

Confidence 52%Complexity Medium–High
Description
미리 볼 수 있는 유물 의뢰가 아이템 테마의 자발적 전투 시험으로 이어지고, 성공하면 유물의 대표 효과가 각성한다.
Basis
direct: 게임은 이미 사냥, 제작, 장비를 연결한다. reasoned: 의뢰는 제작을 자판기 행동이 아니라 기억할 만한 하나의 아이템 여정으로 만들 수 있다.
Rationale
Purposeful Hunt가 표적 획득을 증명한 뒤 빌드 정체성을 깊게 만들 수 있는 주제적 확장이다.
Downsides
후원자, 설계도, 각성 시험은 저장소에 아직 근거가 없고 더 단순한 계약+유물 프로젝트 방향과 겹친다.
