# Personal Flow

Use `$personal-flow` to create or continue task folders under `.flow/tasks/`.

1. Define the task and choose `small`, `standard`, or `large`.
2. Run only the discovery gates justified by risk.
3. Plan, work, review, QA, and close in order; return to the earlier stage when findings change scope or approach.
4. Record all stage outputs in the active task folder.
5. Capture reusable learning on close.

See the global `personal-flow` skill for routing rules and template details.
