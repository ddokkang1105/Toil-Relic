# Task: HUD 텍스트·중앙 패널 크기 조정으로 메인 메뉴와 상태 메시지 레이아웃 겹침을 해소

## Goal

Unity HUD의 텍스트와 중앙 패널 크기·배치를 조정해 메인 메뉴와 상태 메시지가 서로 겹치지 않고 명확하게 읽히도록 한다.

## Scope

- 메인 메뉴, 중앙 패널, 상태 메시지 영역의 현재 레이아웃과 앵커·크기 설정 확인
- HUD 텍스트 크기, 줄바꿈, 여백 및 중앙 패널 크기 조정
- 주요 화면 크기에서 메뉴와 상태 메시지의 비겹침 및 가독성 확인
- 필요한 경우 Unity 설정 문서 또는 관련 검증 아티팩트 갱신

## Non-goals

- 게임플레이 규칙, 전투·보상·성장 로직 변경
- HUD 전체의 신규 디자인 시스템 도입
- 메인 메뉴 흐름이나 상태 메시지 내용 자체의 재설계
- 콘솔 프로토타입 UI 변경(동일한 겹침 문제가 확인되지 않는 한)

## Acceptance criteria

- [ ] 메인 메뉴와 상태 메시지 텍스트가 기본 대상 해상도에서 시각적으로 겹치지 않는다.
- [ ] 중앙 패널 내부의 주요 HUD 텍스트가 잘리거나 의도치 않게 영역 밖으로 넘치지 않는다.
- [ ] 조정 후 메뉴 항목과 상태 메시지의 가독성 및 시각적 우선순위가 유지된다.
- [ ] 관련 Unity Play Mode 또는 수동 화면 검증 결과가 `qa.md`에 기록된다.
- [ ] 변경된 C# 코드가 있다면 관련 빌드·테스트가 통과한다.

## Constraints and risks

- 기존 작업 트리에 사용자 변경이 다수 있으므로 관련 파일의 선행 변경을 보존해야 한다.
- Unity Canvas 스케일러, 앵커, 폰트 자동 크기 설정에 따라 해상도별 결과가 달라질 수 있다.
- 레이아웃 조정은 현재 씬·프리팹·런타임 생성 방식 중 실제 소유 지점을 먼저 확인한 뒤 적용한다.
