# Learning: Promote a surviving idea only after its prerequisites close

## Context

The ranked ideation artifact placed Purposeful Hunt first, Ironclad Save Envelope second, and Tactical Hunt Grammar third. The first two tasks are now closed, and their completion removes the main sequencing reasons to defer the tactical combat slice.

## Reusable insight

When consecutive roadmap leaders close, re-check the next survivor against current code seams and predecessor evidence instead of promoting it mechanically. A previously expensive cross-runtime idea can become the right next move once its prerequisites exist. For interaction work, define a minimal falsifiable grammar before recommending implementation: input cadence, at least two contrasting outcomes, a safe fallback, and accessible presentation.

- Recommending a shared interaction change across console and Unity runtimes.
