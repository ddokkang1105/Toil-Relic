# Task: 장비 비교 기능

## Goal

플레이어가 후보 장비와 선택한 슬롯의 현재 장비를 비교해 장착 결과를 판단할 수 있게 한다.

## Scope

- 콘솔 프로토타입과 Unity 구현에 같은 장비 비교 규칙을 적용한다.
- 후보 장비, 현재 장비, 목적지 슬롯, 능력치 변화량, 장착 후 종합 능력치를 보여준다.
- 비어 있는 선택 슬롯도 정상적인 비교 기준으로 취급한다.
- 기존 12개 물리 슬롯과 슬롯 우선 선택 흐름을 유지한다.
- Unity Camp에 실제 장비 진입점과 전용 장비 화면을 제공한다.
- 후보 선택은 읽기 전용 프리뷰로 유지하고 명시적인 장착 또는 해제 행동만 상태를 변경한다.

## Non-goals

- 인벤토리·장비 획득·드롭·장착 시스템 전체를 재설계하지 않는다.
- 새로운 장비 능력치, 아이템, 희귀도, 밸런스 규칙을 도입하지 않는다.
- HUD에 12개 슬롯 전체를 상시 노출하지 않는다.

## Acceptance criteria

- [ ] 후보 장비와 현재 장비의 이름 및 비교 가능한 능력치를 표시한다.
- [ ] 각 능력치 변화량을 증가·감소·동일 상태로 구분한다.
- [ ] 목적지 슬롯과 장착 후 종합 공격력·방어력·피해 감소·최대 HP를 표시한다.
- [ ] 비어 있는 슬롯에서도 오류 없이 비교 결과를 표시한다.
- [ ] 비교 동작만으로 장비 또는 플레이어 상태가 바뀌지 않는다.
- [ ] 콘솔과 Unity의 비교 규칙 및 결과 능력치가 기능적으로 일치한다.
- [ ] Unity에서 Camp 장비 진입점부터 슬롯·후보·비교·장착/해제·취소까지 실제 화면으로 조작할 수 있다.
- [ ] 취소와 변화 없는 후보는 저장하지 않고, 성공한 장착 또는 해제만 기존 저장 경계를 사용한다.
- [ ] 장착 또는 해제 성공 후 장비 화면과 compact HUD가 갱신되며 장비 화면은 열린 상태를 유지한다.

## Constraints and risks

- 게임플레이 규칙을 바꾸면 콘솔과 Unity 구현을 함께 갱신해야 한다.
- 현재 실제 후보 아이템은 주무기 두 개뿐이므로 선택 슬롯이 비어 있는 비교는 테스트 픽스처나 향후 카탈로그도 수용할 수 있는 계약으로 검증해야 한다.
- Unity에는 전용 장비 진입점과 비교 패널이 아직 없다.
