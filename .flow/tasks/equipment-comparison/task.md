# Task: 장비 비교 기능

## Goal

플레이어가 후보 장비와 현재 장착 장비의 능력치를 비교하여 장착 판단을 할 수 있게 한다.

## Scope

- 콘솔 프로토타입과 Unity 구현에 동일한 비교 규칙을 추가한다.
- 후보 장비, 현재 장착 장비, 능력치별 차이를 표시한다.
- 장착 슬롯이 비어 있는 경우를 명확히 표시한다.

## Non-goals

- 인벤토리·장비 획득·장착 시스템 전체를 재설계하지 않는다.
- 새로운 장비 능력치나 밸런싱 규칙을 도입하지 않는다.

## Acceptance criteria

- [ ] 후보 장비와 현재 장착 장비의 이름 및 비교 가능한 능력치가 표시된다.
- [ ] 각 능력치 차이가 증가·감소·동일 상태로 구분되어 표시된다.
- [ ] 빈 장착 슬롯에서도 오류 없이 비교 결과가 표시된다.
- [ ] 비교 동작은 장비 또는 플레이어 상태를 변경하지 않는다.
- [ ] 콘솔과 Unity의 비교 규칙 및 대상 능력치가 기능적으로 일치한다.

## Constraints and risks

- 게임플레이 로직 변경 시 콘솔과 Unity 구현을 함께 갱신한다.
- 실제 비교 대상 능력치와 Unity UI 진입점은 브레인스토밍에서 확정한다.
